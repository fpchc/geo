# 后端上下文 (Backend Context)

本上下文覆盖 geo 后端管理后台：用户与权限、认证会话、内容生产。系统只有一种账号——用户；不区分 demand/supplier 等账户类型。

## Language

### 账号与认证

**用户 (User)**:
系统唯一的账号主体，代表一个后台使用者；通过登录获得会话，并通过角色获得权限码。
_Avoid_: 账号、账户、account_type、demand、supplier

**超级用户 (Superuser)**:
拥有全部权限码并绕过权限校验的用户标志；它不是角色，也不通过角色授权获得。
_Avoid_: 超级管理员角色、root

**禁用用户 (Disabled User)**:
不能登录、且其全部会话在禁用时终止的用户；重新启用不会恢复旧会话。
_Avoid_: 锁定用户、封禁账号

**登录 (Login)**:
用户以用户名和密码换取一个会话的动作。
_Avoid_: 认证、鉴权

**会话 (Session)**:
一次登录产生的访问令牌/刷新令牌对，以访问令牌的 jti 标识；一个用户可同时拥有多个会话。
_Avoid_: 登录态、token

**访问令牌 (Access Token)**:
用于访问受保护接口的短期令牌，携带用户标识与会话标识。
_Avoid_: JWT

**刷新令牌 (Refresh Token)**:
用于换取新令牌对的长期令牌；每次使用后旧令牌对失效。
_Avoid_: refresh token

**刷新轮换 (Refresh Rotation)**:
使用刷新令牌换取新令牌对时，废弃旧访问令牌与旧刷新令牌的规则。
_Avoid_: 续期

**登出 (Logout)**:
终止当前会话，使该会话的访问令牌立即失效的动作。
_Avoid_: 注销、退出登录

### 认证防护

**登录限流 (Login Rate Limiting)**:
对同一 IP 在时间窗口内登录尝试次数的限制。
_Avoid_: 频率限制、节流

**失败锁定 (Failure Lockout)**:
同一用户名在窗口内连续失败达到阈值后，在锁定时长内拒绝登录。
_Avoid_: 封号、冻结

**登录守卫 (Login Guard)**:
在凭据校验前执行限流与锁定判断的深模块。
_Avoid_: 限流器、拦截器

**锁定 (Lockout)**:
因失败次数达到阈值而暂时拒绝登录的状态。
_Avoid_: 封禁、禁用（禁用是不同的用户状态）

### 权限与菜单

**角色 (Role)**:
菜单授权的命名集合；用户通过角色获得其被授权菜单节点上的权限码。
_Avoid_: 用户组、权限组

**菜单节点 (Menu Node)**:
菜单树中的一个节点，类型为目录、页面菜单或按钮。
_Avoid_: 菜单（单独使用）

**目录 (Directory)**:
只用于分组、不对应前端页面且不携带权限码的菜单节点。
_Avoid_: 文件夹、分组

**页面菜单 (Page Menu)**:
对应一个前端页面路由、可携带权限码的菜单节点。
_Avoid_: 菜单、页面

**按钮 (Button)**:
挂在页面菜单下、表示一个可执行操作且必须携带权限码的菜单节点。
_Avoid_: 权限点、操作点

**权限码 (Permission Code)**:
挂在页面菜单或按钮上的 `{module}:{resource}:{action}` 字符串，用于声明接口所需权限。
_Avoid_: 权限（单独使用）、permission、权限标识

**授权 (Authorization)**:
把菜单节点分配给角色的动作；目录只影响导航结构，权限码来自页面菜单与按钮。
_Avoid_: 赋权、分配权限

**菜单树 (Menu Tree)**:
全部菜单节点按父子关系组成的树，根节点挂在虚拟根 0 下。
_Avoid_: 菜单

**导航树 (Navigation Tree)**:
剔除按钮节点后的菜单树，用于左侧导航。
_Avoid_: 菜单树（单独使用）

**授权树 (Authorization Tree)**:
包含目录、页面菜单与按钮的完整菜单树，用于角色授权。
_Avoid_: 全量菜单

### 内容生产

**创作智能体 (Agent)**:
决定生成风格与基础指令的角色化提示词模板；不等同于 LLM Provider。
_Avoid_: AI、模型、机器人

**内容 (Content)**:
一次内容生产任务的聚合根，保存生成参数、状态、生成次数与当前版本指针。
_Avoid_: 文章、稿件

**内容版本 (Content Version)**:
一次生成产出的不可变正文快照，包含 markdown 正文、标题与字数。
_Avoid_: 草稿、稿件版本

**当前版本 (Current Version)**:
内容聚合根指向的最新内容版本；展示与评审默认针对它。
_Avoid_: 最新稿

**资料 (Material)**:
用户上传并解析为纯文本、供生成提示词引用的文档。
_Avoid_: 附件、文件、素材

**生成 (Generation)**:
根据创作智能体、参数、关键词与资料调用 LLM 产出一个内容版本的动作。
_Avoid_: 创作、写作

**生成次数 (Generation Count)**:
内容提交生成的累计次数，含首次生成与失败重试；达到上限后内容锁定。
_Avoid_: 重新生成次数、regen_count

**重新生成 (Regeneration)**:
在已有内容上再次提交生成，产生新版本并增加生成次数。
_Avoid_: 重试

**评审 (Review)**:
对当前版本按关键词覆盖与评分规则进行评价的动作，可重复执行。
_Avoid_: 审核

**评分 (Score)**:
一次评审产生的结果记录，包含综合分、等级与维度明细；最新一条为当前评分。
_Avoid_: 分数、评级

**等级 (Grade)**:
评分结果中的等级标签。
_Avoid_: 评级、档位

**生成失败 (Generation Failed)**:
生成任务因 LLM 调用失败而结束的状态；失败计入生成次数，可再次生成。
_Avoid_: 错误、异常

### 内容状态

**配置中 (Configuring)**:
内容已创建但尚未提交生成的状态。
_Avoid_: 草稿

**生成中 (Generating)**:
后台生成任务正在运行的状态。
_Avoid_: 处理中

**已生成 (Generated)**:
已产出当前版本、等待评审或留存的状态。
_Avoid_: 完成

**已评审 (Reviewed)**:
当前版本已完成至少一次评审的状态。
_Avoid_: 已审核

**已锁定 (Locked)**:
因生成次数达到上限而禁止继续生成的状态。
_Avoid_: 冻结

**已留存 (Retained)**:
用户确认保留内容的终态；进入后不再生成或评审。
_Avoid_: 已保存、已归档

### 集成

**LLM Provider**:
调用大模型的服务适配层；不承载业务角色或提示词语义。
_Avoid_: 模型、AI

### 界面与导航

**内容创作工作台 (Content Studio)**:
承载生成参数、Markdown 预览与评审的页面，路由 `/content/studio`，也是登录后的默认落地页。
_Avoid_: 仪表盘、首页、生成页

**内容库 (Content Library)**:
浏览、检索与查看历史内容的页面，路由 `/content/library`。
_Avoid_: 内容管理、内容列表

**内容配置 (Content Settings)**:
维护默认提示词与评分规则的页面，路由 `/content/settings`。
_Avoid_: 系统设置、内容设置

**评审区 (Review Panel)**:
内容创作工作台右侧展示总分、维度评分与关键词覆盖的区域。
_Avoid_: 评分面板、审核区

**运营概览 (Operations Overview)**:
展示内容数量、生成成功率、评分分布与趋势的页面，路由 /dashboard；是可选查看页，不是登录后的默认落点。
_Avoid_: 首页、仪表盘

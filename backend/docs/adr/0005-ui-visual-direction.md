# UI 采用 Editorial Precision v2：在「精密仪表」基础上升级，而不是推倒重来

现有前端已按 frontend ADR-0005 落地「精密仪表」：近白画布、蓝色主色、发丝边框、等宽数字、点阵网格、GEO 十字准星、亮/暗双主题，以及 `/dashboard` 运营概览。实际界面仍以卡片墙和 mono 大写标签为主，视觉上接近通用 shadcn 运营后台，缺少内容生产工具应有的编辑感。我们决定升级为 Editorial Precision v2：保留十字准星、Lucide、等宽数字、点阵网格、暗色主题和仪表盘能力；把主色从通用蓝改为墨色 + 信号青柠，把画布改为暖中性，把内容创作页改为左参数、中画布、右评审的三栏工作台，把内容库改为表格 + 右侧详情抽屉，并减少卡片与 mono 标题的使用。登录后的默认落点改为 `/content/studio`；`/dashboard` 保留为「运营概览」，但不再是工作起点。选择升级而非推倒重来，是因为现有实现的导航树、i18n、认证、契约与组件层都值得保留，真正需要换的是视觉 token、信息密度和核心工作台布局。代价是 frontend ADR-0005 需要同步修订为 v2，且暗色 token、图表和链接对比度必须重新验收。设计细则见 `docs/specs/ui-redesign.md`。

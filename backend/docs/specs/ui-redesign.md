# UI 重设计 Spec：Editorial Precision v2

> Status: accepted
> 范围：前端表现层与布局为主；后端业务规则与权限码不变，仅接受第 13 节列出的最小配合改动。
> 关联决策：`docs/adr/0005-ui-visual-direction.md`；这是对 frontend ADR-0005「精密仪表」的视觉升级，不是推倒重来。
> 实现前置：前端代码不在 `backend/` 内；落地前需取得 `../frontend/`（或实际路径）的读写授权。

## 1. 目标与非目标

### 目标

- 建立一套适合内部内容运营、长时间使用的专业工作台视觉。
- 用三栏工作台承载「参数 → 生成 → 预览 → 评审 → 重生成」的完整链路。
- 用统一 token、组件状态和页面骨架消除模板感与拼凑感。
- 让界面像现代 AI 产品，但不落入渐变、玻璃、超大卡片等 AI 模板套路。

### 非目标

- 不扩展仪表盘指标范围；保留 `/dashboard` 并重做为「运营概览」，但不作为默认落地页。
- 不新增主题系统；沿用并校准现有亮/暗双主题 token。
- 不做移动端编辑。
- 不引入摄影、插画、3D 图标或装饰性大图。
- 不重构后端业务、权限、菜单和状态机。
- 不做批量操作、导出、拖拽排序、可配置主题。

## 2. 目标用户与场景

| 项 | 结论 |
| --- | --- |
| 用户 | 内部内容运营、编辑，少量管理员 |
| 使用时长 | 每天连续 4–8 小时 |
| 核心任务 | 配置参数、生成内容、阅读长文、查看评分、反复重生成 |
| 主屏 | 1440–1920 桌面 |
| 移动端 | 只读兜底，不提供编辑 |
| 操作方式 | 鼠标 + 键盘，重度用户使用快捷键 |

## 3. 设计原则

1. **结构优先于装饰。** 高级感来自排版、间距、层级和数据，不来自阴影、渐变和圆角。
2. **一屏一任务。** 核心链路不拆成多步向导，不用弹窗承载生成。
3. **状态是一等公民。** 默认、hover、focus、disabled、loading、empty、error 必须成对设计。
4. **数据不造假。** 没有真实聚合接口就不新增指标或图表；已有运营概览只展示真实数据。
5. **少而准。** 一个强调色、一个图标库、一套圆角、一套动效曲线。
6. **键盘可达。** 所有核心路径可以不碰鼠标完成。
7. **少用卡片。** 页面区块优先用留白和发丝分隔线，不把每个区块都装进卡片。
8. **mono 只表达数据。** 等宽字体用于数字、ID、时间戳，不用于所有标题。

### 明确禁止

- 紫蓝渐变、玻璃拟态、霓虹发光。
- 16–24px 超大圆角、满屏卡片、卡片套卡片。
- 全屏阴影、悬浮聊天气泡、装饰性 emoji。
- 默认 Ant Design / Element Plus 后台皮肤直接上线。
- 用颜色单独表达状态。
- 没有数据支撑的图表和大屏。
- 所有卡片标题都使用 mono 大写 + 宽字距。
- 卡片顶部渐变装饰线。

## 4. Design Tokens

### 4.1 色彩

在现有 `oklch()` token 体系上升级，不另起一套 CSS 变量名。亮色为暖中性，暗色保留完整可用性。

| Token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `--background` | `#F7F7F5` | `#111214` | 页面底色 |
| `--card` | `#FFFFFF` | `#181A1D` | 面板、表格、抽屉表面 |
| `--muted` | `#F2F2EF` | `#23262A` | hover、选中底色、次级区域 |
| `--foreground` | `#111111` | `#F2F2EE` | 主文字 |
| `--muted-foreground` | `#5F5F5A` | `#A3A39D` | 次级文字、说明 |
| `--border` | `#E5E5E1` | `#303338` | 常规分隔线、输入框边框 |
| `--input` | `#D4D4CF` | `#3A3E44` | 输入框边框 |
| `--primary` | `#C6F24E` | `#D6FF6B` | 唯一强调色：当前导航、命中、评分高亮 |
| `--primary-foreground` | `#1A2600` | `#151900` | 强调色上的文字 |
| `--ring` | `#111111` | `#F2F2EE` | 焦点环 |
| `--success` | `#16794A` | `#4ADE80` | 成功、已评审、已留存 |
| `--warning` | `#B45309` | `#FBBF24` | 待评审、需要注意 |
| `--destructive` | `#B42318` | `#F87171` | 失败、删除、错误 |
| `--chart-1..5` | 语义派生 | 语义派生 | 图表专用，必须从 token 读取 |

规则：

- 表中 hex 为参考值；实现写入现有 oklch() token，不新增第二套变量。
- 主按钮使用 --foreground 底 + --background 字，不使用强调色做大面积按钮。
- --primary 只用于小面积高亮和填充，不用于正文文字或链接文字。
- 链接与可点击文字使用 --foreground + 下划线，不依赖 --primary 保证对比度。
- 焦点环使用 `--ring`，不使用强调色。
- 语义色只用于状态，不参与品牌表达。
- 现有 `--chart-1..5` 保留；图表禁止再写 hex 或临时色值。
- 暗色不是反相，必须单独校验对比度与图表可读性。

### 4.2 字体

| 用途 | 字体栈 | 规格 |
| --- | --- | --- |
| UI | `Inter Variable`, `PingFang SC`, `HarmonyOS Sans SC`, `Microsoft YaHei`, sans-serif | 14px / 1.5 |
| 正文预览 | `Source Serif 4`, `Noto Serif SC`, `Songti SC`, serif | 16px / 1.75 |
| 数据 / ID | `JetBrains Mono`, `SFMono-Regular`, monospace | 12–13px |
| 标题 | 同 UI 字体 | 28 / 20 / 16px，字重 600 |
| 表格 | 同 UI 字体 | 13–14px |
| 元信息 | 同 UI 字体 | 12px，`--muted-foreground` |

规则：

- 字重只用 400 / 500 / 600。
- 不使用夸张字距、全大写英文标签。
- 数字列使用 `font-variant-numeric: tabular-nums`。

### 4.3 间距、圆角、阴影

- 间距基于 4px 网格：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 圆角：`4px` 小控件、`8px` 面板与输入框、`12px` 仅弹窗/抽屉。
- 边框优先于阴影：所有面板默认 1px `--border`。
- 阴影只用于浮层：`0 8px 24px rgba(17, 17, 17, 0.08)`。
- 不使用多层阴影、彩色阴影、内阴影。

### 4.4 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| hover / focus | 120ms | ease-out |
| 展开 / 收起 | 160ms | ease-out |
| 抽屉 | 200ms | ease-out |
| Toast | 3000ms 后消失 | — |

规则：

- 只动 `opacity` 和 `transform`。
- 不做页面切换动画、自动轮播、视差。
- 支持 `prefers-reduced-motion: reduce`，降级为无动画。
- 生成中使用呼吸点，不使用旋转 loading 占据画布。

### 4.5 图标

- 统一使用 Lucide。
- 尺寸：16px 行内、18px 导航、20px 工具栏。
- 线宽 1.5px。
- 后端菜单 `icon` 字段映射到 Lucide 图标名。
- 禁止 emoji 当图标，禁止混用图标库。

## 5. App Shell

### 5.1 结构

| 区域 | 规格 |
| --- | --- |
| 左侧导航 | 232px，可折叠为 56px 图标栏 |
| 顶部栏 | 52px |
| 内容区 | 自适应，横向内边距 24px |
| 表单页最大宽度 | 1200px |
| 工作台 | 不限最大宽度，最小可用宽度 1280px |

### 5.2 左侧导航

- 顶部：GEO 十字准星 + 字标，代码原生 SVG，不使用位图 logo。
- 分组「内容生产」：内容创作、内容库、内容配置。
- 分组「系统管理」：用户管理、角色管理、菜单管理。
- 当前项：左侧 2px `--foreground` 指示条 + `--muted` 底色。
- 底部：用户菜单（当前用户、账户设置、退出登录）。
- 折叠态只显示图标，hover 显示 tooltip。
- 导航由后端导航树驱动；文案通过 path 映射 i18n key，不维护第二份前端静态导航清单。
- 导航接口失败时 fail-closed，显示错误壳和重试，不回退静态菜单。

### 5.3 顶部栏

- 左侧：面包屑。
- 右侧：全局搜索入口（显示 `Ctrl K` 提示）、用户头像。
- 不使用通知中心（当前没有通知接口）。

### 5.4 默认落地页

登录后默认进入 `/content/studio`；无内容权限时回退 `/dashboard`。保留 `/dashboard` 作为「运营概览」，但不作为默认落地页。

## 6. 页面蓝图

### 6.1 登录页 `/login`

- 左右 52 / 48 分屏。
- 左侧：低对比抽象纹理（AI 生成的唯一图像资产）+ 产品名 + 一行定位语。
- 右侧：白色区域，360px 登录表单。
- 表单：用户名、密码、登录按钮、错误提示。
- 不做人物插画、卖点列表、第三方登录、注册入口。

### 6.2 内容创作工作台 `/content/studio`

三栏布局：

| 区域 | 宽度 | 内容 |
| --- | --- | --- |
| 左栏 | 360px | 智能体、创作参数、关键词、字数、额外提示词、资料 |
| 中间 | 自适应，最小 640px | Markdown 画布 |
| 右栏 | 320px，可折叠 | 评审区 |

左栏自上而下：

1. 智能体选择：7 选 1 的单选列表，每项显示图标、名称、一行描述。不使用卡片网格。
2. 创作参数：2×2 网格，受众 / 平台 / 行业 / 角度。支持输入，也提供常用值选择。
3. 关键词：标签输入，回车追加，支持删除。
4. 目标字数：滑块 + 数字输入，两者同步。
5. 额外提示词：默认折叠，展开后为 textarea。
6. 资料上传：拖拽区 + 已上传文件列表，显示文件名、类型、字符数。
7. 底部固定操作条：「生成内容」主按钮，右侧显示当前重生成次数。

中间画布：

- 顶部：内容标题、状态胶囊、字数、版本下拉、重生成次数徽标。
- 主体：Markdown 预览，使用衬线正文字体。
- 空状态：说明「配置左侧参数后开始生成」。
- 生成中：画布内显示进度状态，不用模态遮罩。
- 生成失败：内联错误 + 重试按钮。
- 已锁定：显示「已达到 10 次重生成上限」并禁用重新生成。

右栏评审区：

- 总分环：96px，8px 线宽，中心 28px 等宽数字。
- 等级徽标。
- 维度列表：维度名 / 横向进度条 / 得分 / 权重。
- 关键词覆盖：放大的覆盖率百分比 + 标签列表。
- 操作：「开始评审」「重新生成」。
- 未评审时显示空状态，不显示 0 分。

### 6.3 内容库 `/content/library`

- 全宽表格。
- 列：标题 / 状态 / 智能体 / 创建人 / 重生成次数 / 更新时间 / 操作。
- 筛选：状态、智能体、标题关键词。
- 分页：每页 20 条。
- 表头吸顶，无斑马纹。
- 行 hover：`--muted`。
- 点击行：右侧滑出 480px 详情抽屉。
- 详情抽屉 Tab：正文 / 评分 / 信息。
- v1 不做批量操作。

### 6.4 内容配置 `/content/settings`

- 左侧 200px 分区导航：默认提示词、评分规则。
- 右侧表单区，最大宽度 880px。
- 默认提示词：大号 textarea + 字符数。
- 评分规则：JSON 编辑区 + 格式校验 + 预览。
- 底部固定保存条，离开未保存时二次确认。

### 6.5 系统管理页

`/system/users`、`/system/roles`、`/system/menus` 共用一套模式：

- 顶部：标题 + 主操作按钮。
- 筛选区：单行，条件超过 4 个时折叠。
- 表格：沿用第 7 节表格规范。
- 新增 / 编辑：小表单用弹窗，复杂表单用右侧抽屉。
- 角色授权：左侧角色列表 + 右侧授权树。
- 菜单管理：树形表格 + 右侧编辑抽屉。
- 删除：必须二次确认并显示对象名称。

### 6.6 运营概览 `/dashboard`

保留现有 dashboard 能力，但去掉「四张 KPI 卡片 + 卡片墙」的模板感：

- 顶部：标题 + 日期范围 + 智能体筛选 + 刷新。
- 指标条：4 个指标横向排列，用发丝分隔线，不各自包卡片。
- 主图：一张趋势图，占据主要视觉面积。
- 次要区：状态分布、评分分布并排，使用紧凑列表 + 细进度条。
- 空状态、未就绪状态、错误状态都保持在页面内，不用整页错误。
- 不新增没有接口支撑的图表。
- dashboard 的定位是「运营概览」，不是默认工作起点。

## 7. 组件规范

### 7.1 按钮

| 类型 | 用途 | 样式 |
| --- | --- | --- |
| Primary | 页面主操作 | `--foreground` 底、`--background` 字 |
| Secondary | 次要操作 | 白底、`--border` 边框、墨色文字 |
| Ghost | 工具栏、行内操作 | 透明底，hover 变 `--muted` |
| Danger | 删除、不可逆操作 | `--destructive` 文字或底色 |

尺寸：默认高 32px，紧凑 28px，主要操作 36px。圆角 6px。

### 7.2 输入框

- 高度 32px，圆角 6px，1px `--border`。
- focus：2px `--foreground` 边框 + 2px offset 焦点环。
- 错误：`--destructive` 边框 + 字段下方错误文案。
- 禁用：`--muted` 底 + `--muted-foreground` 文字。

### 7.3 状态胶囊

- 结构：6px 圆点 + 12px 文字。
- 背景透明或 `--muted`，不使用高饱和填充。
- 状态映射：

| 状态 | 颜色 |
| --- | --- |
| 配置中 | 灰 |
| 生成中 | 蓝 + 呼吸点 |
| 生成失败 | 红 |
| 已生成待评审 | 琥珀 |
| 已评审 | 青绿 |
| 已锁定 | 灰 + 锁图标 |
| 已留存 | 绿 |

### 7.4 表格

- 表头高 36px，行高 40px。
- 表头吸顶，下边框 `--border`。
- 无斑马纹。
- 行 hover `--muted`；选中行左侧 2px 墨色指示条。
- 数字右对齐、等宽数字。
- 时间格式 `YYYY-MM-DD HH:mm`。
- 空数据：表体中央空状态，不在页面中央。
- 加载：8 行骨架。
- 横向滚动限制在表格容器内。

### 7.5 抽屉、弹窗、Toast

- 抽屉：右侧滑入，480px，200ms。
- 弹窗：仅用于短表单和确认，最大宽度 560px。
- Toast：右上角，3 秒消失，支持手动关闭。
- 破坏性操作不使用 Toast 代替确认。

### 7.6 评分与关键词

- 总分使用圆环，不使用雷达图。
- 维度使用横向进度条。
- 关键词标签：命中 = 青柠圆点 + 命中次数；未命中 = 红色描边。
- 覆盖率使用大号等宽数字展示。
- 不做热力图。

### 7.7 卡片与分区

- 卡片只用于真正独立的容器：表格、图表、抽屉内容。
- 表单分组、筛选区、页面区块优先使用「标题 + 发丝分隔线 + 留白」，不套卡片。
- 禁止卡片套卡片。
- 卡片标题默认使用 sans 字体 14px / 500；只有数据标签、ID、时间戳使用 mono。
- 禁止把所有标题都做成 mono 大写 + 宽字距；这会制造模板感。
- 卡片内边距统一 20px；表格型卡片可用 0 内边距 + 表头贴边。
- 渐变只允许出现在登录页纹理和图表内部，不允许做卡片顶部装饰线。

## 8. 状态与反馈

| 场景 | 处理 |
| --- | --- |
| 页面加载 | 骨架屏，不使用全屏 spinner |
| 列表为空 | 一句说明 + 一个主操作 |
| 接口失败 | 内联错误 + 重试按钮 |
| 生成中 | 画布内进度状态 + 禁用重复提交 |
| 生成失败 | 错误原因 + 重试，计入重生成次数 |
| 达到 10 次上限 | 内联锁定提示，禁用重生成，仅允许确认留存 |
| 保存成功 | Toast「已保存」 |
| 删除成功 | Toast + 列表局部刷新 |
| 409 冲突 | 内联提示，不使用全局错误页 |

## 9. 文案规范

- 动宾结构、短句、无感叹号。
- 不使用「哎呀」「Oops」「太棒了」等口语。
- 错误文案 = 发生了什么 + 怎么办。
- 空状态 = 一句说明 + 一个主操作。

示例：

- 空内容库：「还没有内容。创建第一篇内容」
- 生成失败：「生成失败：模型服务超时。重试」
- 锁定：「已达到 10 次重生成上限，只能确认留存。」
- 保存成功：「已保存」
- 删除确认：「删除用户「张三」？此操作不可撤销。」

## 10. 无障碍

- 正文对比度 ≥ 4.5:1。
- 键盘焦点：2px `--foreground` 描边 + 2px 偏移。
- 所有图标按钮必须有 `aria-label`。
- 桌面点击目标 ≥ 32px；触屏目标 ≥ 44px。
- 状态不能只靠颜色区分。
- 抽屉、弹窗、命令面板支持 `Esc` 关闭。
- 支持 `prefers-reduced-motion`。

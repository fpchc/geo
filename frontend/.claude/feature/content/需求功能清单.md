# 内容生产模块 · 需求功能清单（POC）

> 范围：仅「内容生产模块」AI 生成链路。本期为初步验证版。
> 定位：需求梳理产物，描述「做什么、约束是什么」，不含实现方案。

---

## 一、功能清单

| 编号 | 功能 | 需求描述 | 本期范围 |
|------|------|----------|----------|
| F-01 | 智能体选择 | 提供 7 个智能体供单选，选中后载入其后台配置的基础提示词 | ✅ 本期 |
| F-02 | 创作参数 | 目标受众、发布平台、行业领域、创作角度，仅作为生成的风格/语气/结构约束 | ✅ 本期 |
| F-03 | 关键词输入 | 标签形式，可回车追加多个；作为生成必须覆盖的词，同时是评审比对基准 | ✅ 本期 |
| F-04 | 目标字数 | 滑块设置目标字数，作为生成长度约束 | ✅ 本期 |
| F-05 | 额外提示词 | 用户可选填；填则拼入 prompt，不填则套用默认提示词 | ✅ 本期 |
| F-06 | 默认提示词 | 系统内置，仅后台可修改，前端不暴露 | ✅ 本期（内容不细化） |
| F-07 | 资料上传 | 可选上传资料，全文直接注入模型；校验文件大小与格式 | ✅ 本期 |
| F-08 | Prompt 组装 | 按固定顺序拼装智能体提示词+参数+关键词+字数+提示词+资料 | ✅ 本期 |
| F-09 | 内容生成 | 调用大模型，输出 Markdown 文档 | ✅ 本期 |
| F-10 | md 预览 | 前端渲染生成的 md 供用户查看 | ✅ 本期 |
| F-11 | 关键词评审 | 评审智能体对生成内容做关键词覆盖审核并出评分 | ✅ 本期 |
| F-12 | 评分规则配置 | 评分规则后台可调整，本期不定死具体分值 | ✅ 本期 |
| F-13 | 重新生成限制 | 单篇内容重新生成上限 10 次，达上限锁定 | ✅ 本期 |

---

## 二、关键规则约束

| 项 | 规则 |
|----|------|
| 关键词命中口径 | **原样命中 + 自然融入**；关键词须原样出现在正文，由提示词约束自然融入语句，禁止堆砌罗列 |
| 生成与评审一致性 | 生成端「原样写入」与评审端「原样命中率」使用同一套关键词规则 |
| 上传资料注入方式 | 全文直接喂给模型 |
| 上传资料大小上限 | 依据**模型上下文窗口**设定，而非纯存储容量 |
| 上传资料格式 | 白名单控制（具体格式待定义） |
| 创作参数作用范围 | 仅影响文风，不触发任何投放/平台适配逻辑 |
| 默认提示词权限 | 仅后台可改 |
| 评分规则 | 后台可配，本期不固化分值/及格线 |
| 重新生成上限 | 单篇 10 次，失败重试同样计入 |
| 输出格式 | Markdown |

## 三、本期明确不做（Out of Scope）

| 项 | 说明 | 归属 |
|----|------|------|
| 自动发布/投放 | 人工手动发布，系统不对接任何平台 | 后续 |
| 内容真实性核验 | 默认提示词让 AI 自由生成，不做幻觉/事实校验 | 后续 |
| 时效与更新机制 | 生成内容的失效、更新频率不做 | 后续 |
| Query 细分 | 暂用智能体区分内容类型，不细化到 query 意图 | 后续 |
| 量级/成本治理 | 并发、限流、成本控制不做 | 后续 |
| 默认提示词内容细化 | 本期仅保留后台可改的入口，不细化其内容 | 后续 |
| GEO 效果衡量 | 被引用率、首位提及、复述准确度等不做 | 后续 |

## 四、待澄清 / 待定义项（进入开发前需补）

| 编号 | 事项 | 影响 | 优先级 |
|------|------|------|--------|

| Q-05 | 默认提示词内容 | 决定输出结构，本期后台可改可后置 | 中 |

## 五、认知备忘（不影响本期开发）

本期以「引擎检索关键词能否找到原文」作为验证信号，验证的是内容**可被检索/收录**，属于「能被搜到」层面。它**不等于** GEO 的终点——「被 AI 引擎在回答中引用、正向复述」。后续做真实 GEO 效果衡量时，衡量口径应切换为提及率 / 首位提及率 / 跨引擎覆盖率 / 复述准确度，不应以「能搜到」作为「GEO 成功」的结论上报。

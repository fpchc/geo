# 09 · 收敛内容工作台交互：上传 / 版本 / 续编 / 提示词

Type: grilling
Status: open
Blocked by: 01

## Question

内容工作台的剩余交互缺口如何收敛，哪些进 MVP？

需要明确：

- 资料上传：前端大小/格式校验、后端限制的来源（`system_settings` 或配置）、解析失败提示、删除与后端一致性。
- 版本历史：列表、切换预览、当前版本标识；是否支持回滚/设为当前版本。
- 从内容库打开并续编/重生成：路由与状态传递、刷新后的创作态恢复。
- 智能体基础提示词：展示方式（只读预览/折叠），是否允许用户临时修改。
- 导出入口与格式选择。
- 表单规则：关键词是否必填、目标字数范围、智能体只显示 enabled、额外提示词长度。

输出：交互决策、页面/组件拆分、状态管理方案；必要时用 `/prototype` 产出低保真交互稿。

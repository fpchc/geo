# 04 · 确定账号安全、密码重置与 401 策略

Type: grilling
Status: open
Blocked by: —

## Question

生产 MVP 的账号安全底线如何落地？

需要明确：

- 重置密码流程：管理员设置临时密码、强制首次改密，还是后端生成一次性密码；前端交互与接口契约。
- 密码策略：长度、复杂度、错误提示；是否强制改密。
- 登录限流/失败锁定的前端提示与后端契约（后端实现为外部依赖）。
- Token 存储策略（localStorage / sessionStorage / cookie）与 XSS 风险取舍。
- 401 统一处理：axios、上传、下载、导出等所有请求的刷新/跳登录行为。
- 图形/滑块验证是否提交后端校验；是否移除验证码登录、注册等空实现页面。

输出：安全决策、前后端契约、验收场景；标注哪些需要后端配合。

# 10 · 定义运营看板聚合 API 契约与看板交互

Type: grilling
Status: open
Blocked by: 01

## Question

看板已定四类指标、ECharts、后端新增聚合 API。需要把口径、契约和交互定清楚。

需要明确：

- 指标口径：内容产量与状态分布、生成成功率与失败原因、评分分布与关键词覆盖、重生成/留存/锁定。
- 时间范围、筛选维度（智能体/状态/用户）、时区与默认值。
- 聚合端点、请求参数、响应字段；是否需要概览 + 趋势两个端点。
- 空态、错误态、加载态；刷新策略与缓存。
- ECharts 图表选择：卡片、折线、柱状、饼图；是否支持下钻。
- 后端实现为外部依赖：契约、验收数据、联调窗口。

输出：后端聚合 API 契约（外部依赖）、前端页面蓝图、指标定义表、验收数据构造方案。

Type: grilling
Status: open
Blocked by: —

## Question

业务文案全量中英双语如何组织、迁移和验收？

需要明确：

- locale key 的组织与命名（按页面/模块/通用）；与 Vben 框架文案的边界。
- 现有硬编码中文（内容生产、看板、系统页）的迁移清单与优先级。
- 翻译工作流：谁翻译、如何审校、缺 key 的降级策略。
- 日期、数字、时区、货币的 locale 格式化。
- 语言切换与持久化；登录前后语言一致性。
- 后端错误码/消息的翻译归属：前端映射还是后端返回多语言。
- en-US 缺省 key 的补齐与 CI 检查。

输出：i18n 规范、文案清单、迁移步骤、验收标准。

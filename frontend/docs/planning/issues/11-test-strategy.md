# 11 · 确定 E2E 冒烟与测试策略

Type: grilling
Status: open
Blocked by: 01, 05

## Question

Playwright 冒烟覆盖什么，测试策略如何与 CI、真实后端配合？

需要明确：

- 主链路用例：登录 → 生成 → 评审 → 留存；RBAC 越权；看板只读；中英切换。
- 测试数据与环境：真实后端还是专用测试环境；测试账号与数据清理。
- CI 集成：触发时机、并行、重试、trace/截图/视频保留。
- 单元/组件测试边界：工具函数、请求层、复杂组件；覆盖率目标（如有）。
- 现有 `test` 脚本实为启动 dev 的修正。
- 失败判定与 flaky 处理。

输出：测试策略、首批 E2E 用例清单、CI 集成方案、测试数据方案。

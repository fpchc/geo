# 运营后台采用 Editorial Precision v2 视觉语言，亮色默认并保留暗色主题

> Status: superseded by [ADR-0007](0007-ui-direction-c.md)（2026-10-29）。本文保留为历史决策记录；其禁止渐变、玻璃拟态、大圆角与页面切换动画的约束不再生效。

现有界面最初收敛为「精密仪表」：近白画布、蓝色主色、发丝边框、等宽数字、点阵网格、GEO 十字准星，并已具备亮/暗双主题。实际验收后，界面仍以卡片墙和 mono 大写标签为主，接近通用 shadcn 运营后台，缺少内容生产工具应有的编辑感。我们决定升级为 **Editorial Precision v2**：保留十字准星、Lucide、等宽数字、点阵网格、暗色主题、导航树与 i18n；把画布改为暖中性，把主色从通用蓝改为信号青柠，把主按钮改为墨色底，把内容创作页改为三栏工作台，把内容库改为表格 + 详情抽屉，并减少卡片与 mono 标题。亮色仍是默认主题；`--primary` 只用于填充和指示，文字与图标使用 `--primary-strong`。登录后的默认落点改为 `/content/studio`；`/dashboard` 保留为「运营概览」，但不再是工作起点。

## Considered Options

- **继续沿用蓝色精密仪表**：实现成本最低，但无法解决卡片墙与 mono 标题造成的模板感。
- **暗色控制台**：科技冲击力强，但长时间内容阅读与高密度表格更易疲劳，且会丢掉现有亮色基线。
- **渐变玻璃 / 大圆角卡片**：视觉噪音大，在表单、表格和弹窗密集的后台难以维持对比度与可读性。

## Consequences

- `--primary` 改为信号青柠，只用于填充、当前导航指示和评分高亮；文字链接改用 `--foreground` + 下划线，避免青柠文字对比度不足。
- 新增 `--primary-strong` 用于亮色主题下的图标与强调文字。
- 保留并重新校准亮/暗两套 token；图表必须从 `--chart-1..5` 读取颜色，禁止写死 hex。
- 卡片标题、表单 label、表头默认改回 sans；mono 只用于数字、ID、时间戳。
- 设计细则与验收清单见 `../specs/ui-redesign.md`。

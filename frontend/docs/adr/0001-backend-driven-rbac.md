# 采用后端菜单驱动的 RBAC

生产 MVP 需要让运营在菜单管理中调整可见菜单，并避免前端静态路由与后端权限数据漂移。我们决定把 `accessMode` 从 `frontend` 切换到 `backend`：导航由后端菜单树生成，页面与按钮权限统一使用菜单/按钮节点上的权限码。代价是后端必须提供“当前用户可见菜单”的能力——现有 `/menus/tree` 仅系统管理员可访问。

## Consequences

- 菜单、路由、按钮三层由同一棵后端菜单树驱动，新增页面必须同时落菜单种子。
- 非系统管理员需要“我的菜单”能力；这是 backend 模式的前置依赖。
- 前端路由仍保留，但只作为组件映射与兜底，不再作为权限来源。

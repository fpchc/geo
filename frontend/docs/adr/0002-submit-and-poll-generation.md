# 内容生成采用提交 + 轮询，不在 MVP 引入 SSE

内容生成是耗时的大模型调用，前端现有实现依赖后端并不存在的 SSE 流式接口。MVP 决定收敛到后端已具备的「提交生成 → 任务轮询 → 读取内容详情」链路，SSE 不进入本期；这样前端可以复用统一请求层、401 刷新与错误处理，也不必为流式协议维护第二套状态机。

## Consequences

- 生成页必须处理轮询间隔、超时、刷新/离开后的任务恢复，以及 409 锁定与任务过期。
- 删除或停用 stream API；若未来恢复流式体验，需重新评估任务恢复与权限/刷新逻辑。
- 任务完成后正文从内容详情读取，轮询响应不携带正文。

# web-admin 内容运营后台

web-admin 是 GEO 项目的内部运营后台，本期只服务内容运营团队：生成、评审、留存内容，并通过只读看板观察产出。本文件的术语是该上下文的统一语言。

## Language

### 内容生产

**内容 (Content)**:
一次可独立生成、评审和留存的内容实体，包含一个或多个版本，并以当前版本对外呈现。
_Avoid_: 文章、稿件、文档

**内容版本 (Content Version)**:
内容在某次生成或重新生成后产生的 Markdown 正文快照；只有当前版本可被评审和留存。
_Avoid_: 草稿、副本

**生成任务 (Generation Task)**:
一次异步生成或重生成工作的执行记录，状态为 pending / running / completed / failed；任务完成后正文需从内容详情读取。
_Avoid_: 作业、Job

**智能体 (Agent)**:
预置的内容生成角色，带有基础提示词，决定内容的类型与风格。
_Avoid_: 机器人、模型

**资料 (Material)**:
用户上传、在生成时全文注入提示词的参考文本。
_Avoid_: 附件、文件

**创作参数 (Creation Params)**:
受众、发布平台、行业领域、创作角度四项风格约束；只影响文风，不触发投放或平台适配。
_Avoid_: 投放参数、平台配置

**关键词 (Keyword)**:
必须在正文中原样出现并自然融入的目标词，同时作为评审的比对基准。
_Avoid_: 标签、词条

**评审 (Review)**:
对内容当前版本执行关键词覆盖审核并给出评分的过程。
_Avoid_: 审核、检查

**评分 (Score)**:
评审产出的总分、等级与维度得分；同一内容只保留最新一次评分。
_Avoid_: 打分、分数

**重新生成 (Regenerate)**:
基于同一内容再次生成新版本；成功和失败都计入重新生成次数。
_Avoid_: 重试、再次生成

**锁定 (Locked)**:
内容重新生成次数达到上限后的状态；只能留存，不能继续生成。
_Avoid_: 冻结、封存

**留存 (Retain)**:
用户确认当前版本为最终交付内容，内容进入已留存状态且不再重生成。
_Avoid_: 保存、归档、发布

**内容工作台 (Content Studio)**:
从选择智能体到生成、评审、重新生成、留存的操作页面。
_Avoid_: 创作页、生成页

**内容库 (Content Library)**:
查询已生成内容及其详情、版本和评分的页面。
_Avoid_: 内容管理、内容列表

### 权限与导航

**访问模式 (Access Mode)**:
决定菜单与权限来源的模式：`frontend` 由前端静态路由控制，`backend` 由后端导航树控制；本项目采用 `backend`。
_Avoid_: 权限模式、鉴权模式

**菜单树 (Menu Tree)**:
后端下发的完整授权结构，节点类型为目录、菜单、按钮；包含只承载权限码的按钮节点，只用于角色授权。
_Avoid_: 路由表、导航配置

**导航树 (Navigation Tree)**:
菜单树剔除按钮节点后的当前用户可见结构；驱动导航、面包屑、页面标题与路由守卫。
_Avoid_: 侧边栏数据、菜单配置

**权限码 (Permission Code)**:
形如 `content:content:generate` 的授权标识，挂在菜单或按钮节点上，用于控制页面与按钮可见性。
_Avoid_: 权限标识、permission string

**角色 (Role)**:
一组菜单与权限码的集合；用户通过角色获得菜单和操作权限。
_Avoid_: 用户组、权限组

**系统管理 (System Management)**:
维护用户、角色、菜单三类基础数据的后台区域。
_Avoid_: 后台设置、系统设置

### 交付与质量

**生产 MVP**:
在 ≤50 用户、≤500 篇/天规模下，可容器化部署并具备 RBAC、账号安全、中英双语、CI/监控的最小可运营版本。
_Avoid_: 正式版、1.0

**主链路 (Main Flow)**:
登录 → 生成 → 评审 → 重新生成 → 留存 → 内容库可见的端到端路径；是 MVP 的统一验收口径。
_Avoid_: 核心流程、业务流程

**运营看板 (Dashboard)**:
只读的聚合视图，展示内容产量、状态分布、生成成功率、评分分布等运营指标。
_Avoid_: 报表、数据大屏

**外部依赖 (External Dependency)**:
本期只定义前端契约、由后端或其他团队另行排期实现的能力，如看板聚合、导出、登录限流。
_Avoid_: 后端任务、待办
